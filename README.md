# Todo List REST API

Backend-сервис для управления списком задач с хранением данных в реляционной базе данных.

## Функциональность
- CRUD-операции над задачами (создание, чтение, обновление, удаление).
- Фильтрация и выборка задач по статусу выполнения.
- Персистентное хранение данных через ORM.

## Технологический стек
- Java 25, Spring Boot 3.5.6
- Spring Web (REST API), Spring Data JPA
- PostgreSQL
- Maven, Lombok
